# Chaukanna: Android client

The victim's phone app for Chaukanna (चौकन्ना, "watchful"), a live guardian against
digital-arrest / KYC scam calls. Calls run app-to-app over LiveKit. The Python bridge
(`chaukanna-audio-bridge`) hears both legs, classifies them, and sends this app data
messages. The app shows the live risk, whispers a pre-recorded warning, and after a
high-risk call shows what n8n already did, along with the 1930 complaint for the human to confirm.

Screens: **call guardian** (gauge, chips, live transcript, Protected badge) → **alarm**
(bilingual warning + whisper, Hang up / I understand) → **post-call** (n8n results,
complaint draft in the call language + English, Confirm & Submit 1930 Report).

## Run

```bash
export PATH=$PATH:~/flutter/bin
flutter test                      # 53 tests, no device needed
flutter build apk --debug         # build/app/outputs/flutter-apk/app-debug.apk
```

With no `--dart-define`s the app runs **offline**: swipe in from the right edge (or tap
the thin handle) to open the **Demo Simulator**. "Full scripted scam call" plays the
whole demo in about 40 s: call_started → rising verdicts → two whispers → n8n
incident → call_ended → post-call. It runs through the same JSON parser as LiveKit
and never touches the network.

Live build:

```bash
flutter build apk --debug \
  --dart-define=LIVEKIT_URL=wss://<project>.livekit.cloud \
  --dart-define=LIVEKIT_TOKEN=<JWT for identity "victim", TTL that outlives the event>
```

| define | default | meaning |
|---|---|---|
| `LIVEKIT_URL`, `LIVEKIT_TOKEN` | empty | Room + token. The identity **must** be `victim`, because the bridge only sends to that identity. The debug log prints the token's identity and expiry at connect. |
| `LIVEKIT_TOKEN_URL` | empty | Alternative: GET → `{"token","url"}` |
| `N8N_APPROVAL_WEBHOOK` | `https://n8n.premortem.tech/webhook/chaukanna-approve` | Fallback when no `approve_url` arrived |
| `VICTIM_ID` / `VICTIM_NAME` / `VICTIM_LANG` | `demo-victim-1` / `Papa` / `hi` | Payload id, simulated family alert, clips preloaded before the call language is known |
| `MUTE_MIC_DURING_WHISPER` | `true` | Pause the victim's mic while a warning plays, so the caller can't hear it |
| `SPEAKER_DEFAULT` | `true` | Calls start on the loudspeaker |
| `WHISPER_ROUTE` | `call` | `call` = voice-call audio route; `media` = like music (simulated calls always use media) |
| `AUTO_BLOCK_KNOWN` | `true` | Hang up after the known-scammer warning |

Don't put two phones on the same victim token: LiveKit kicks the first, and the app
then stops reconnecting and says why.

## Contract (CONTRACTS §3–5)

- Data topic `chaukanna.verdict` (untagged packets accepted too). Types: `call_started`,
  `verdict` (or a bare Verdict), `incident`, `heartbeat`, `call_ended`. Unknown types are ignored.
- The app stays in the room between calls. Call boundaries come from `call_started` / `call_ended`,
  with a fallback of `caller-*` participants joining and leaving. All state resets per call,
  and late verdicts for an ended call are ignored.
- Whisper: only when the bridge says `whisper: true`. The short clip plays first, then the full one, both from
  `lib/generated/whisper_clips.dart` (generated by `tts_asset_generator`, not hand-edited).
  The same clip plays at most once per 20 s, and a newer warning interrupts an older one. A failure
  shows on the alarm screen, as a snackbar, and in the simulator's debug log.
- Approval POSTs to the incident's `approve_url`, then to the webhook if that fails or is
  a localhost URL. Additive fields: `complaint_text_local`, `complaint_language`, `known_scammer`.
- OTP-like digit runs (4–8 digits, spaced or Indic digits) are masked in the transcript and evidence.
  Phone numbers, dates, 1930 and rupee amounts are kept.

## Needs a real phone to verify

- Whether the whisper is audible over the call on earpiece vs speaker (`WHISPER_ROUTE`).
- Whether echo cancellation alone would hide the whisper from the caller. The mic pause makes that moot,
  unless you turn it off.
- Mic permission prompt timing (the app publishes the mic once at connect, then mutes it until a call).
